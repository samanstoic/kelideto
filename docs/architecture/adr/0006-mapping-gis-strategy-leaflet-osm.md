# ADR-006: بهره‌گیری از Leaflet.js و کاشی‌های OpenStreetMap بدون کلیدهای انحصاری
**وضعیت:** پذیرفته‌شده (Accepted)  
**تاریخ:** ۲۰۲۶-۱۰  
**تصمیم‌گیرندگان:** Software Architect, Senior React Developer, GIS Engineer  

---

## ۱. زمینه و صورت مسئله (Context)
سرویس‌های تجاری نقشه مانند Google Maps یا سرویس‌های داخلی تجاری (مانند نشان یا بلد) نیازمند دریافت API Key اختصاصی، پرداخت هزینه بر اساس بازدید و پذیرش ریسک تحریم یا تغییر شرایط سرویس هستند. علاوه بر این، نقشه سیستم باید امکان کش آفلاین بسته‌های کاشی (Offline Map Tiles) برای مناطق مشخص شهری را دارا باشد تا متخصص یا مشتری بدون هزینه اضافی بتواند لایه‌های بصری نقشه را مشاهده کند.

## ۲. گزینه‌های بررسی‌شده (Alternatives Considered)
1. **Google Maps API:** هزینه‌بر، نیازمند کارت اعتباری بین‌المللی، فاقد امکان رسمی ذخیره‌سازی آفلاین کاشی‌ها و ریسک تحریم آی‌پی‌های ایران.
2. **Mapbox GL JS:** قدرتمند؛ اما نیازمند Access Token تجاری و محدودیت در مدل‌های آفلاین بدون اکانت تجاری.
3. **Leaflet.js + OpenStreetMap / Carto Tiles (انتخاب‌شده):** کتابخانه متن‌باز و بسیار سبک (~۴۰ کیلوبایت)، بدون نیاز به هیچ کلید انحصاری، سازگار با استانداردهای OGC و کاشی‌های XYZ/MBTiles و دارای افزونه‌های غنی برای کش در IndexedDB (`leaflet.offline`).

## ۳. تصمیم (Decision)
- به‌کارگیری کتابخانه متن‌باز **Leaflet.js** در رابط فرانت‌اند (React-Leaflet یا اجرای مستقیم Leaflet در کامپوننت‌های تایپ‌اسکریپت).
- تأمین کاشی‌های نقشه از سرورهای مجاز بر پایه داده‌های **OpenStreetMap (OSM)** با رعایت شرایط استفاده و لایسنس ODbL (Open Database License) و انتساب الزامی حق نشر (Attribution: `© OpenStreetMap contributors`).
- پشتیبانی از پکیج‌های کاشی آفلاین محلی (دانلود بسته‌های از پیش فشرده‌شده کاشی‌های زوم ۱۰ تا ۱۶ برای کلان‌شهرها) و نگهداری آن‌ها در کش مرورگر از طریق Service Worker و IndexedDB.

## ۴. پیامدها (Consequences)
- **مزایا:**
  - استقلال صددرصدی پلتفرم از سرویس‌دهندگان تجاری و عدم وجود هزینه لایسنس نقشه به ازای هر درخواست.
  - عملکرد تضمین‌شده نقشه در صورت قطعی اینترنت بین‌الملل (استفاده از کش محلی یا سرورهای کاشی داخلی).
  - بارگذاری سبک و سازگاری بالا با انواع مرورگرهای تلفن همراه.
- **محدودیت‌ها و راهکارها:**
  - کاشی‌های پیش‌فرض OSM فاقد قابلیت Reverse Geocoding (تبدیل خودکار مختصات به پلاک متنی) در حالت آفلاین هستند؛ بنابراین آدرس‌دهی دقیق توسط کاربر از طریق انتخاب نقطه روی نقشه و ثبت متن نشانی محلی تکمیل می‌گردد.
