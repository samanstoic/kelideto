# ADR-009: فرانت‌اند HTML، CSS و JavaScript ماژولار

**وضعیت:** پذیرفته‌شده (Accepted)  
**تاریخ:** ۲۰۲۶-۱۰  
**جایگزین:** ADR-002  
**دامنه:** رابط‌های وب KeyPro و PWA؛ بک‌اند Laravel و قراردادهای API خارج از دامنه‌اند.

## زمینه

برای ساده‌سازی پشتهٔ اجرایی و نگهداری پروژه، رابط‌های کاربری باید بدون React، JSX یا TypeScript اجرا شوند. مهاجرت باید رابط‌های موجود، دسترس‌پذیری، RTL، رفتار واکنش‌گرا، احراز هویت، APIها و قابلیت‌های آفلاین را حفظ کند.

## تصمیم

- صفحات و تعاملات با HTML معنایی، CSS بومی و ماژول‌های JavaScript پیاده‌سازی می‌شوند.
- Vite برای توسعه و ساخت assetهای Laravel باقی می‌ماند.
- router، state، API client و اجزای UI مشترک در ماژول‌های Vanilla سازمان‌دهی می‌شوند؛ برای هر بارگذاری سند تنها یک entry مالک root رابط است.
- Laravel، session/token، قراردادهای API، پایگاه داده و منطق دامنهٔ بک‌اند تغییر نمی‌کنند.
- Leaflet و Service Worker در صورت نیاز محصول باقی می‌مانند؛ این وابستگی‌ها React یا TypeScript را وارد نمی‌کنند.
- Vitest و ESLint ابزارهای آزمون و کیفیت کد JavaScript هستند؛ typecheck مخصوص TypeScript اجرا نمی‌شود.

## پیامدها

- وابستگی‌های React و ابزارهای TypeScript از build فرانت‌اند حذف می‌شوند.
- ساختار state و ارتباط بین صفحات باید صریح و قابل‌آزمون باقی بماند.
- آزمون‌های رابط بر رفتار قابل‌مشاهدهٔ DOM و قراردادهای API تمرکز می‌کنند.
- توسعهٔ بعدی باید سازگاری RTL، دسترس‌پذیری صفحه‌کلید، رفتار آفلاین و رگرسیون قراردادهای موجود را پوشش دهد.
