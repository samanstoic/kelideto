# ADR-002: انتخاب React، TypeScript و Vite برای فرانت‌اند با استایلینگ Vanilla CSS مدرن
**وضعیت:** منسوخ‌شده؛ جایگزین‌شده با [ADR-009](./0009-vanilla-javascript-frontend.md)
**تاریخ:** ۲۰۲۶-۱۰  
**تصمیم‌گیرندگان:** Software Architect, Senior React/TypeScript Developer  

---

## ۱. زمینه و صورت مسئله (Context)
فرانت‌اند پلتفرم KeyPro باید شامل ۴ پرتال (مشتری، متخصص، دیسپچ و ادمین) با قابلیت اجرای روان در مرورگرهای موبایل، تبلت و دسکتاپ باشد. پشتیبانی از تایپ‌استاتیک (Type Safety) برای قراردادهای داده با بک‌اند، سرعت بیلد بالا، اجرای بدون باگ و طراحی بصری سفارشی، لوکس، کاملاً RTL و فارسی الزامی است. همچنین مطابق با دستورالعمل‌های پروژه، استفاده از کتابخانه‌های کم‌عمق مانند TailwindCSS بدون درخواست کاربر ممنوع بوده و استایل‌نویسی بر پایه CSS بومی پیشرفته با متغیرهای طراحی (Design Tokens) الزام شده است.

## ۲. گزینه‌های بررسی‌شده (Alternatives Considered)
1. **Next.js (React Fullstack):** امکان SSR؛ اما به دلیل ماهیت داشبوردی و نیازمندی به PWA سبک و بسته‌بندی مستقل اپلیکیشن‌های متخصص و مشتری در یک Monorepo فرانت‌اند و اتصال به API مستقل Laravel، پیچیدگی اضافی سرور Node را تحمیل می‌کند.
2. **Vue.js 3:** فریم‌ورک عالی؛ اما تایپ‌اسکریپت و اکوسیستم نقشه‌های تعاملی و ابزارهای ساخت در React و اکوسیستم PWA جامع‌تر است.
3. **React 18/19 + TypeScript + Vite (انتخاب‌شده):** سبک‌ترین، سریع‌ترین و استانداردترین ابزار برای SPAهای تعاملی، نقشه‌محور و PWA با مدیریت استیت مشخص.

## ۳. تصمیم (Decision)
- بهره‌گیری از **React 18+ با TypeScript** و ابزار ساخت **Vite**.
- معماری استایل‌ها مبتنی بر **Vanilla CSS پیشرفته (CSS Variables / Design System Tokens)** با پشتیبانی کامل از RTL، فونت‌های فارسی استاندارد (مانند Vazirmatn/Shabnam)، طراحی لایه‌ای Glassmorphism، تم تاریک (Dark Mode) و پالت رنگی اختصاصی لوکس (سرمه‌ای تیره، طلایی متالیک و فیروزه‌ای ایمن).

## ۴. پیامدها (Consequences)
- **مزایا:**
  - بیلد فوق‌العاده سریع با Vite و Hot Module Replacement (HMR).
  - تایپ‌سیفتی کامل در تبادل DTOها با بک‌اند و جلوگیری از خطاهای زمان اجرا در فرانت‌اند.
  - استقلال کامل از پکیج‌های حجیم استایل؛ بهینگی حجم نهایی باندل JS و بارگذاری آنی در اینترنت‌های ضعیف موبایل ایران.
- **محدودیت‌ها و راهکارها:**
  - نیاز به نگهداری منظم متغیرهای CSS و کلاس‌های کامپوننت؛ سیستم طراحی مستند در فایل‌های توکن (`tokens.css` و `index.css`) پایه‌گذاری می‌شود.
