# راه‌اندازی اولیه سرور

ویزارد `/setup` برای ساخت مدیر ارشد و ذخیره تنظیمات پایه به API متصل است. نصب فقط یک‌بار انجام می‌شود؛ پس از آن endpoint نصب ایجاد مدیر دیگری را نمی‌پذیرد. صفحه وضعیت اتصال دیتابیس، اجرای migrationها، `APP_KEY`، تنظیمات امنیتی محیط عملیاتی و اتصال سرویس‌های بیرونی را از سرور دریافت می‌کند.

## پیش از باز کردن ویزارد

1. وابستگی‌های backend و frontend پروژه را نصب کنید.
2. `.env` را بسازید، اطلاعات اتصال دیتابیس و تنظیمات زیر را وارد کنید و کلید رمزنگاری را تولید کنید:

   ```sh
   cp .env.example .env
   php artisan key:generate
   ```

   ```dotenv
   APP_ENV=production
   APP_DEBUG=false
   APP_URL=https://your-domain.example
   INITIAL_SETUP_TOKEN=<at-least-32-random-characters>
   ```

   `INITIAL_SETUP_TOKEN` را با مولد رمزنگارانه و مستقل بسازید و فقط برای نصب اولیه در اختیار مدیر قرار دهید. این مقدار در پاسخ API، دیتابیس، audit log یا فایل‌های فرانت‌اند ذخیره نمی‌شود. ویزارد حتی با رمز عبور قوی، بدون این توکن از ساخت نخستین مدیر جلوگیری می‌کند.

3. تنظیمات را cache کنید، migrationها را اجرا و assetهای production را بسازید:

   ```sh
   php artisan config:cache
   php artisan migrate --force
   npm ci
   npm run build
   ```

4. برنامه را پشت TLS و با پورت ثابت `8001` اجرا کنید. در محیط عملیاتی، وب‌سرور و process manager پروژه باید به `127.0.0.1:8001` متصل شوند؛ `artisan serve` فقط برای توسعه است.

## تکمیل نصب

1. با HTTPS به `https://your-domain.example/setup` بروید.
2. وضعیت‌های سرور را بررسی کنید. اگر اتصال دیتابیس یا migrationها آماده نیست، آن‌ها را در deployment اصلاح کنید؛ این موارد از داخل مرورگر قابل تغییر نیستند.
3. توکن یک‌بارمصرف، نام مدیر، نام کاربری و رمز عبور قوی را وارد کنید.
4. نام نمایشی، اطلاعات پشتیبانی، منطقه زمانی، مهلت پاسخ مأموریت و مدت نگهداری موقعیت را تعیین کنید. تنظیمات و مدیر در یک تراکنش و همراه با audit ثبت می‌شوند. واحد پول فعلی سامانه ریال (`IRR`) است.
5. پس از نصب، `INITIAL_SETUP_TOKEN` را از محیط سرور حذف کنید، cache پیکربندی را بازسازی و processهای PHP را restart کنید:

   ```sh
   php artisan config:cache
   ```

   وضعیت نصب در دیتابیس قفل شده است و حذف توکن، نصب انجام‌شده را باز نمی‌کند.
6. برای ورود بعدی، از بخش «ورود مدیر با نام کاربری و رمز عبور» در `/auth` استفاده کنید.

## سرویس‌های بیرونی

SMS، Web Push و درگاه پرداخت فقط با adapter و credential معتبر سرور متصل گزارش می‌شوند. در غیر این صورت وضعیت آن‌ها `disconnected` یا تأییدنشده می‌ماند؛ ویزارد هیچ secret یا credential این سرویس‌ها را در تنظیمات عمومی ذخیره نمی‌کند. این credentialها را در محیط سرور تنظیم و سپس سرویس را جداگانه بررسی کنید.
